# CineReserve - Admin Dashboard & Analytics (Low-Fidelity Wireframe)

A low-fidelity UI prototype and wireframe for the **CineReserve** movie ticket reservation system, created for a **Software Engineering UML project**.

## Overview
This prototype models the **Admin Dashboard and Analytics** module, demonstrating UI structure, navigation architecture, and administrative components without production design overhead (strictly grayscale, rectangular components, and clear hierarchy).

### Implemented Modules & Features
1. **Top Header**: Logo monogram, global query search bar, notification flyout, and admin profile dropdown.
2. **Left Navigation Sidebar**:
   - `1. Dashboard` (Summary metrics, trend charts, recent bookings, quick actions)
   - `2. Movies` (Catalog, filter toolbar, pagination)
   - `3. Theatres` (Venue directory, screen & seating capacity)
   - `4. Shows` (Show scheduling, seat mapping triggers)
   - `5. Users` (Role-based access administration)
   - `6. Bookings` (Ledger, payment filters, ticket actions)
   - `7. Analytics` (Booking volume & collection analytics)
   - `8. Reports` (Audit statements & export options)
   - `9. Settings` (System parameters & configurations)
   - `10. Logout` (Confirmation modal)
3. **Interactive Modals**:
   - Add Movie Modal
   - Add Theatre Modal
   - Create Show Modal
   - Logout Confirmation Modal

## How to Run
Open `index.html` directly in any modern web browser or start a local server:
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000`.
